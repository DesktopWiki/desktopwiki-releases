# DesktopWiki releases

Installers for [DesktopWiki](https://desktopwiki.com), a wiki for a family or small team that runs on one Windows PC, by EmuKey LLC.

DesktopWiki checks this repository for updates (when it starts and every few hours). Each release:

- is tagged with the app's calendar version, `YY.MM.DDNN` (for example `26.11.2001`: 20 November 2026, first build that day);
- carries `DesktopWiki.msi` as an asset, signed by **EmuKey LLC**. The app installs an update only when the MSI's signature is valid and from that publisher.

`beta.json` says whether the beta is still running and when beta builds stop.

The source code is not in this repository.
